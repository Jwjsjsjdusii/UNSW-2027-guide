## 部署
1. 解压 ZIP。
2. 将 index.html、manifest.json、sw.js、icon.svg、README.md 上传到现有 GitHub 仓库根目录并覆盖。
3. Commit changes，等待 GitHub Pages 部署成功。
4. 重新打开网站；若仍显示旧版，清理该站点旧 PWA 缓存并重新添加到主屏幕。
