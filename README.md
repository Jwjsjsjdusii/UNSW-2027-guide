# My Study Life · Personal Edition V4.4

## V4.4 更新内容
- 首页改为个人工作台：保留倒计时，移除旧首页下方重复概览。
- 倒计时可切换：抵达澳洲、语言班开课、正课开课、回国、返校；支持设置回国/返校日期并添加自定义目标。
- 首页日历增加双模式：事件日历 / 每周课表。
- 课表支持手动添加、编辑、删除每周重复课程，按星期、时间、课程类型、教室和颜色展示。
- 移除独立「留学时间轴」栏目，避免与工作台重复。
- 租房中心改为五个折叠模块：找房平台、区域与通勤、看房检查、合同与 Bond、防诈骗。
- 看房检查和合同/Bond 改为可勾选清单，保存在本地浏览器。
- 兼职求职合并重复的学生签证工作条件说明，改为签证条件、工资权益、招聘渠道三个模块。
- 首页增加近期安排、本月花销和快捷入口。

## 数据兼容
继续使用原有浏览器本地数据键，V4.3 已保存的个人资料、航班、事件、预算和消费记录会继续保留。
新增的倒计时目标、课表和租房检查清单也会保存到本地。
导出 JSON 备份时包含课表、倒计时目标及租房清单状态。
本地存储不等于云同步；换设备或浏览器前请先导出备份。

## 课表说明
当前支持手动录入每周重复课程；没有接入学校账号或 LMS 的自动同步。
后续可增加 CSV / 文本导入。课程时间与地点请以学校官方课表为准。

## 政策核验提醒
学生签证工作条件应以个人 VEVO 和签证批准条件为准。Home Affairs 当前公开说明：课程开始前通常不能工作；课程进行期间通常每两周最多 48 小时；课程不在 session 时通常可不限时工作，但存在例外。
NSW 一般住宅租赁的 Bond 通常不超过四周租金；Condition Report 应在取得房屋占有后七天内返还并保留副本。具体租赁类型和最新规定应以政府官方信息为准。

## GitHub Pages 部署
1. 解压 ZIP。
2. 将 `index.html`、`manifest.json`、`sw.js`、`icon.svg`、`README.md` 五个文件上传到 GitHub 仓库根目录，覆盖同名文件。
3. Commit changes，等待 GitHub Pages 部署成功。
4. 关闭旧 PWA 页面后重新打开；如果仍是旧版，清理该站点数据并重新添加到主屏幕。
